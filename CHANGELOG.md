# Changelog

## 1.0.1 (2026-11-08)

- A `name` or `first_name` written as a nested YAML map no longer shows as "[object Object]"; the note's file name is used instead. In a list of anniversaries, empty items and maps are skipped.
- Checked on every push by Obsidian's own lint rules (eslint-plugin-obsidianmd), the type check, the tests and the build.

## 1.0.0 (2026-10-15)

- First release of the Lite edition: birthdays and anniversaries from your people notes, today and the coming days in a side view, and a notice at startup.
